# 생성 재질 v1

내장 `image_gen`으로 만든 오크·석재 기본색 이미지입니다. 원본 생성 파일을 이 폴더에 복사했으며 업스케일·크롭·색 보정은 하지 않았습니다.

| 파일 | 실제 해상도 | 사용 |
| --- | --- | --- |
| `oak.png` | 1254 × 1254 | 라이트 오크 바닥·수납장 |
| `limestone.png` | 1254 × 1254 | 웜 스톤 바닥·상판·욕실 마감 |

최종 요청 프롬프트 전문은 [prompts.json](prompts.json), 실제 해상도·해시·출처는 [manifest.json](manifest.json)에 있습니다. 프롬프트에는 2048 정사각형을 요청했지만 실제 결과물은 위 해상도입니다. 2K·4K 텍스처라고 표기하지 않습니다.

요청 요약: 정면 직교 투영, 평평한 확산광, 재질만 가득 찬 반복 가능한 표면, 그림자·하이라이트·문자 없는 내추럴 오크와 웜 아이보리 석재. 반복 이음새 없는 이미지를 요청했지만 완전한 타일 연속성을 보장하지는 않습니다.

실측/스캔 PBR 세트가 아닌 생성 기본색 이미지입니다. 표면 거칠기는 코드에서 설정하고, 이 이미지에 대응하는 측정된 노멀·높이 맵은 없습니다. 기존 절차적 텍스처의 노멀 맵은 새 무늬와 맞지 않으므로 해당 대체 재질에서 해제합니다.

이미지 한 반복을 1.2m에 대응시키는 것은 디자인용 설정값입니다. 기존 Blender UV의 미터 기준 반복값을 보정하며 모델의 벽·방·가구 치수는 변경하지 않습니다. 실제 아크로리버파크 시공 자재를 재현했다고 주장하지 않습니다.
