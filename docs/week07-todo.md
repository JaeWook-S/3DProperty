# 7주차 MVP 작업과 다음 순서

2026년 10월 8일 내부 회의 기준으로, 아크로리버파크 112A에서 일반 사용자가 공간을 둘러보고 가구를 배치하는 MVP를 먼저 완성한다. 기존 도면 안에서 고르는 추천 컨셉을 추가하고, 이미지 입력부터 가구 생성·배치까지 연결한다. 치수 추정의 정량 개선과 인하대 도면 준비는 이어서 진행한다.

담당 이름은 기존 팀 역할과 회의의 작업 배분을 함께 반영했다. 이번 S1 구현 순서는 최신판 공유 → 미니맵 → 엘리베이터/반입 경로다. S2/S3 코드를 대신 수정하거나 각자의 결과를 완료로 표시하지 않는다.

## 이번 회의에서 좁힌 범위

- 추천 컨셉은 먼저 현재 112A 도면 안에서 구현한다. 임의의 인테리어 사진을 다른 도면에 자동 매핑하는 기능은 후속 과제다. (14:39–17:20)
- 가구 치수 추정은 유지한다. 모델·데이터를 조사하고 공통 표본에서 정량적인 개선을 확인하되 MVP의 모든 기능을 학습 완료까지 기다리게 하지 않는다. (18:24–22:29)
- 모바일 조이스틱은 이미 공유된 구현을 통합한다. 모바일을 위한 추가 확장은 이미지 입력·가구 연동보다 후순위다. (21:09–21:40)
- 홈투어 영상·이미지 생성은 부가 기능으로 미룬다. (15:47)
- 엘리베이터 반입이 어려울 때 창문 경로도 검토하는 아이디어가 나왔다. 실제 승강기·복도·출입구·창호 치수와 운반 방향 없이 반입 가능 여부를 확정하지 않는다. (08:22–09:36)

## 이미 구현한 범위

- 112A 기본형·확장형 v3와 미터 좌표, 참고 이미지에 따른 빈 방·서재·안방 배치.
- 예시 단지의 여러 동·층 선택과 A동 22층 시연 세대 연결.
- 실시간 2D/3D 편집, 겹침 허용/제한 토글과 배치 경고, 하단 편집 도구.
- 눈높이·몸체 폭·시야각·화면 크기 보정, 발코니 선택.
- 공식 단지 사진을 사용하는 참고 외부 배경. 실측 단지 배치나 실제 22층 조망은 아니다.
- `origin/main`의 모바일 입력 구현: `83eafbb`, 병합 `3446aaa`. 통합 후 검사는 아래 기록에서 구분한다.

## 공유와 검증

- 발표 기준은 `week-06-presentation` 태그(`72b8007`)에 보존한다.
- 이후 변경은 `feat/post-week06-improvements`에 커밋하고 PR로 공유한다. 팀원의 커밋과 저자 정보를 유지하며 force push하지 않는다.

`origin/main`의 모바일 구현을 v3 스튜디오와 병합했다. 단위 25개, 브라우저 9개(모바일 4·기존 뷰어 4·단지/편집 화면 1), 빌드가 통과했다. PC 마우스 잠금과 터치 이동을 모두 확인했고, 모바일 입력 모듈 및 모바일 검사 원본은 팀원 커밋과 동일하다. 기존 500KB 번들 경고는 남아 있다.
