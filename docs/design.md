# CORTEX 디자인 기준

홈, 집들이, 스튜디오 화면이 같은 규칙을 따르도록 정리한 문서입니다. 값은 `src/house-tours/theme.css`의 `:root` 토큰에 있습니다. 새 화면을 만들거나 바꿀 때는 이 문서를 먼저 고칩니다.

## 방향

- 기준은 오늘의집 웹입니다. 흰 바탕에 사진이 주인공이고, 글은 작고 촘촘하게 씁니다. 강조색은 행동을 부르는 곳에만 씁니다.
- "AI가 만든 사이트" 같은 인상을 주는 기본값을 쓰지 않습니다. 근거로 삼은 자료는 다음과 같습니다.
  - [avoid-ai-design](https://github.com/funboy322/avoid-ai-design): 크림 바탕 + 포인트색, 대문자·자간 넓힌 라벨, 01/02 번호, 버튼 화살표 등 목록
  - [925studios — AI slop web design](https://www.925studios.co/blog/ai-slop-web-design-guide): 막연한 문구, 똑같은 둥글기와 그림자
  - [Impeccable anti-patterns](https://www.mintlify.com/pbakaus/impeccable/concepts/anti-patterns)

## 쓰지 않는 것

| 하지 않기 | 대신 |
| --- | --- |
| Inter, 시스템 기본 글꼴 | Pretendard (한글 서비스 표준, 오늘의집도 사용) |
| 크림 바탕 + 짙은 초록 | 흰 바탕, 회색 단계, 강조색은 버튼·선택 상태에만 |
| `MY HOME`, `01 / SELECT A HOME` 같은 영문 대문자 라벨 | 한국어 짧은 라벨 (`우리 집`, `새로운 집 찾기`) |
| 버튼 끝의 `→`, 장식용 `✓ ↔ ↻` 기호 | 동작을 말하는 문구, 필요할 때만 선 아이콘 |
| 모든 것이 둥근 알약 모양, 큰 그림자, 흐림 효과 | 사진 6px, 버튼 6px, 필터 4px. 그림자는 떠 있는 메뉴와 시트에만 |
| 사진 위 진한 그라데이션과 큰 흰 글씨 | 글은 사진 아래. 예외는 홈 대표 집들이 한 곳 |
| 화면을 똑같은 세 칸으로 나누기 | 대표 콘텐츠 하나 + 보조 카드, 그 아래 섹션 |
| 앞으로 생길 기능 예고, 데모·출처·가정을 밝히는 작은 안내 글 | 화면에는 지금 쓸 수 있는 것만. 출처와 가정은 문서(`docs/`)와 코드에 |

## 글자

- 본문 15px, 자간 -0.3px, 줄 간격 1.6–1.85
- 섹션 제목 20px 700, 페이지 제목 26px, 집들이 제목 30px
- 카드 제목 15–16px 700 두 줄까지, 메타 13px `--sub`

## 구성 요소

- **헤더**: 로고, 주 메뉴 세 개(우리 집 · 새로운 집 찾기 · 집들이, 17px 700, 현재 위치는 강조색), 검색창(홈·집 찾기·집들이에서만)
- **카드**: 4:3 실제 사진, 아래에 제목 · 집 정보(주거형태 · 평수 · 방 · 가족) · 우리 집과 같은 조건. 아주 비슷한 집만 사진에 작은 배지. 호버 때 사진만 3% 확대
- **필터**: 회색 버튼 + 드롭다운(휴대폰에서는 아래쪽 시트). 고른 태그는 아래에 칩으로 보이고 `초기화`로 지웁니다
- **버튼**: `.btn` 높이 40px, 주 버튼 `.btn-primary`. 같은 화면에 주 버튼은 하나만 둡니다
- **최근 적용한 테마**: 사이드바에서는 렌더 썸네일 + 이름 · 색감 · 평면과 때 + `다시 적용` 한 줄, 홈에서는 같은 내용을 4열 카드로. 지금 적용된 테마는 버튼 대신 강조색 `적용 중`

## 사진

- 집들이와 홈의 공간·스타일 사진은 실제 집 사진입니다(Unsplash 라이선스, `src/house-tours/tours.js`). 상업적 사용이 가능하고 허락이 필요 없습니다. Unsplash 이미지 주소로 불러오고 작가를 표시합니다. 렌더처럼 보이는 사진(3D 시각화)은 고르지 않습니다.
- 우리 집 미리보기는 CORTEX 3D 모델 렌더링이고(`tools/house-tours/render-tours.mjs`), 캡션에 `CORTEX 3D`라고 적습니다.
- 오늘의집 등 다른 서비스의 사진은 쓰지 않습니다. 사용자와 회사에 저작권이 있습니다.
- 단지 사진은 ACRO 공식 소개 자료입니다(`assets/location/acro-river-park/provenance.json`).
- 둘러보기 창밖은 한강·도심 실제 사진(Unsplash)과 ACRO 공식 단지 사진입니다([창밖 풍경](window-view.md)).
