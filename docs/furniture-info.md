# 가구 상품 정보 카드

1인칭 둘러보기에서 가구를 바라보고 **P**를 누르면 상품 카드가 열린다. 카드가 열린 동안 WASD·방향키 이동과 마우스 시점 회전은 멈추고 커서를 사용할 수 있다. 다시 **P**를 누르거나 **닫고 둘러보기 계속**을 누르면 카드를 닫고 같은 위치·시선에서 이동을 재개한다. **Esc**는 카드를 닫고 일시정지 상태로 남는다.

오른쪽 3D 평면/꾸미기 영역에서는 가구에 마우스를 올려 **+** 버튼으로 작은 상품 카드를 연다. 왼쪽 2D 평면에는 상품 정보 동작을 추가하지 않았다. 둘러보기의 P와 기존 E 문 조작은 그대로 사용한다.

## 사용 방법

1. `3DProperty`에서 `npm ci`, `npm run dev`를 실행하고 `http://127.0.0.1:5173/`을 연다.
2. 공간과 방을 선택하고 **둘러보기**를 시작한다.
3. 4m 이내의 가구 중앙을 화면 중앙 조준점으로 바라본다. 낮은 가구는 마우스로 시선을 아래로 내린다.
4. **P · 가구 정보 보기** 안내가 나타나면 P를 누른다.
5. 커서로 상품 링크를 클릭할 수 있다. 링크는 새 탭에서 열린다. 돌아온 뒤 P를 누르면 이동을 계속한다.

벽이나 다른 물체가 가리면 뒤쪽 가구는 선택되지 않는다. 등록된 이동 가능 가구가 대상이며 벽·문·고정 주방 집기는 상품 선택 대상에 포함하지 않는다.

## 오른쪽 3D 영역의 + 버튼

1. **우리 집**의 2D·3D 나란히 보기 또는 **꾸미기** 화면에서 오른쪽 3D 가구에 마우스를 올린다.
2. 가구 중앙에 하나만 나타나는 원형 **+** 버튼을 누른다. 마우스로 가구의 어느 부분을 가리키더라도 버튼은 같은 가구 중앙에 표시된다. 마우스를 올리는 것만으로 카드는 열리지 않는다.
3. 가구 옆의 작은 카드에서 모델 썸네일, 상품명, 가격, 판매처를 확인하고 **상품 보러가기**를 누를 수 있다.
4. **×**, 같은 가구의 **+** 버튼, 카드 바깥 클릭 또는 Esc로 닫는다. 다른 가구의 +를 누르면 해당 상품으로 바뀐다.

카드는 오른쪽 3D 영역 안에 배치되고 전체 화면을 가리지 않는다. 3D를 드래그하거나 휠로 확대·축소하면 카드를 닫고 기존 카메라 조작을 수행한다. 버튼 클릭은 방 선택이나 가구 이동으로 전달되지 않는다. 카드가 닫힌 상태에서 마우스가 왼쪽 2D로 이동하면 + 버튼이 사라지며, 2D 가구 선택·이동 동작은 기존과 같다.

이 화면에서는 카메라와 가구 사이의 4m 거리 제한을 사용하지 않는다. 잘라서 숨긴 천장·벽 윗부분은 선택을 막지 않지만, 실제로 보이는 벽이나 다른 물체 뒤의 가구는 선택할 수 없다. 둘러보기나 다른 공간으로 전환하면 +와 카드를 정리한다.

구성 참고: [아키스케치 공식 제품 태그 안내](https://www.archisketch.com/ko/blog/6848fb53b7dabf0012869990)의 가구 태그와 구매 페이지 연결 흐름을 참고했다.

## 상품 정보 수정

편집 파일은 **`public/furniture-products.yaml`** 하나다. 둘러보기 P 카드와 오른쪽 3D의 + 카드가 같은 파일을 읽는다. 현재 상품명·가격·판매처·주소는 예시이며 실제 상품을 확인한 값이 아니다.

```yaml
version: 1
defaults:
  price: 199000
  currency: KRW
  seller: "임시 판매처"
  url: "https://example.com/"
  placeholder: true

products:
  sofa:
    name: "내가 수정한 소파 상품명"
    price: 1290000
    currency: KRW
    seller: "내가 수정한 판매처"
    url: "https://example.com/products/sofa"
    placeholder: false
```

- `name`: 카드에 표시할 상품명. 생략하면 실제 가구 이름을 사용한다.
- `price`: 쉼표와 원 단위 없이 숫자만 입력한다. 모르는 가격은 `null`로 두면 판매처 확인 문구가 나온다.
- `currency`: `KRW`, `USD` 같은 통화 코드.
- `seller`: 판매처 표시 이름.
- `url`: 실제 상품 페이지의 `https://` 주소. 빈 문자열은 구매 버튼을 비활성화한다.
- `placeholder`: 예시 정보는 `true`, 실제 확인한 정보로 수정한 뒤에는 `false`로 바꾼다.
- 공통 값은 `defaults`에 쓰고, 상품별로 달라지는 값만 해당 항목에 적어도 된다.
- YAML 들여쓰기는 공백으로 맞추고, 상품명·판매처·URL은 따옴표로 감싼다. 기존 `products` 아래에 항목을 추가하고 같은 키를 두 번 작성하지 않는다.

카드를 열 때마다 YAML을 다시 읽는다. 개발 중 저장으로 화면이 새로고침되면 원하는 화면에서 다시 카드를 연다. 배포할 때는 `npm run build` 결과의 `dist/furniture-products.yaml`도 서버에 반영한다. 상품 정보 파일을 읽지 못하면 카드에 오류와 예시 정보를 표시하며 그대로 닫을 수 있다.

### 어떤 키를 수정하면 되는가

| 키 | 대상 |
| --- | --- |
| `sofa` | 기본 배치 소파 |
| `stool` | 스툴 |
| `king` | 킹 침대 |
| `single` | 싱글 침대 |
| `desk` | 책상 |
| `chair` | 의자 |
| `cc0-modern-arm-chair-01` | CC0 라운지 체어 |
| `cc0-sofa-02` | CC0 클래식 소파 |
| `cc0-modern-coffee-table-01` | CC0 커피 테이블 |
| `cc0-dining-chair-02` | CC0 식탁 의자 |
| `catalog-sofa-2790`, `catalog-stool-980` | 해당 ID로 등록된 소파·스툴 |

일치하는 항목을 찾는 순서는 **배치 ID → CC0 모델 ID → 가구 종류(kind)**다. 동일 모델을 복제하면 같은 상품 정보를 공유한다. 특정 배치만 다르게 표시하려면 그 배치 ID를 `products`의 키로 추가한다. 목록에 없는 가구도 공통 값으로 표시된다.

새 가구의 키를 확인하려면 개발 주소에 `test=1`을 추가해 열고, 해당 카드가 열린 상태에서 개발자 도구 콘솔에 다음을 입력한다.

```js
window.__walkthrough.getState().furnitureInfo
// { id: '배치 ID', kind: '가구 종류', productKey: '현재 사용한 YAML 키' }
```

`kind`를 YAML에 추가하면 같은 종류 전체에, `id`를 추가하면 그 배치 하나에 적용된다. 이 조회 도구는 개발 서버의 `test=1`에서만 제공된다.

## 썸네일과 범위

CC0 가구는 Three.js 가구 카탈로그가 사용하는 동일한 `preview.png`를 사용한다. 미리보기가 없는 기본·추천·생성 가구는 선택한 실제 3D 그룹을 복제하여 썸네일을 렌더링한다. 임의의 상품 사진을 대신 붙이지 않는다. 모델 형상과 재질을 사용하되 썸네일 촬영 조명·각도는 현재 시점과 다를 수 있다. 실제 공간의 모델·치수·재질·충돌 데이터는 변경하지 않는다.

P는 키를 계속 누르고 있어도 한 번만 작동한다. 둘러보기 카드 표시 중 E·테마 단축키 등은 작동하지 않는다. 브라우저가 마우스 재잠금을 거절하면 기존 **이어서 둘러보기** 버튼으로 재시도한다. 둘러보기는 PC 키보드 P, 오른쪽 3D의 + 버튼은 마우스 hover를 기준으로 한다. 별도의 모바일 상품 버튼이나 VR 헤드셋 입력은 추가하지 않았다.

## 검증

```bash
node --test tests/furniture-info.test.js
PLAYWRIGHT_CHANNEL=chrome npx playwright test tests/furniture-info.browser.js
PLAYWRIGHT_CHANNEL=chrome npx playwright test tests/furniture-hover.browser.js
npm run build
```

브라우저 검사는 실제 Three.js 모델·포인터 잠금으로 P 반복 전환, 커서 해제, 이동·시점 고정, 새 탭 링크와 YAML 변경/오류를 확인한다. 추가 검사는 3D hover/+ 클릭, 작은 카드의 영역 내 배치, CC0 미리보기, 회전 드래그 유지, 모드 전환 정리와 2D 상품 동작 비활성화를 확인한다.
