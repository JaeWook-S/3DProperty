# 추천 컨셉 배치 (W7-06)

112A 세대 안에서 가족 구성과 좋아하는 분위기를 고르면, 미리 정의한 가구 배치 4가지 중 잘 맞는 순서로 추천하고 색감까지 함께 적용합니다. 임의의 인테리어 사진을 다른 도면에 자동으로 옮기는 기능은 아니며, 현재 112A 기본형·확장형 도면에 맞춘 사전 정의 배치입니다.

## 사용 방법

1. `npm run dev` 후 `http://localhost:5173/?studio=1`에서 A동 → 22층 → **세대 보기**로 112A에 들어갑니다. 첫 화면은 장소 선택의 **전체 보기**(2D 평면 + 3D)입니다.
2. 상단 탭 **둘러보기 / 꾸미기 / 컨셉 보기** 중 **컨셉 보기**를 누르면 항상 ‘우리 가족에 맞춘 배치’ 목록이 열립니다.
3. **가족 구성**(1인 · 재택 / 신혼 2인 / 영유아 3인 / 4인 가족)과 선택 사항인 **좋아하는 분위기**를 고르면 카드 순서와 ‘가장 잘 맞아요 / 함께 고려해 볼 만해요’ 표시가 바뀝니다. 카드의 작은 평면은 실제 배치를 그 컨셉의 추천 색으로 그린 것입니다.
4. **이 컨셉 적용**을 누르면 2D 평면과 3D에 가구가 놓입니다. 화면은 목록에 그대로 머물고, 적용된 카드에서 색감 3가지를 바로 바꿀 수 있습니다.
   - **이 집에서 걸어보기**: 거실 북서쪽 모서리에서 소파·러그·창 쪽을 바라보며 1인칭 둘러보기를 시작합니다.
   - **자세히**: 색감 설명, 바닥 마감 맞추기, 시간대(낮·해질녘·밤), 공간별 구성(누르면 3D가 그 방으로 이동), 가족 구성 체크, 배치 점검, **가구 직접 다듬기**를 보여줍니다. 컨셉 보기 탭을 다시 누르면 목록으로 돌아갑니다.
   - 목록 아래 **기본 배치로 되돌리기**는 컨셉 가구를 지우고 원래 배치와 색으로 돌아갑니다.
5. 하단의 저장·복원은 컨셉과 색감까지 함께 기억합니다. 휴대폰(폭 650px 이하)에서는 아래에서 올라오는 시트로 열리고, 적용하면 시트가 접혀 평면·3D와 카드의 색감·버튼이 함께 보입니다.

### 걸으면서 테마 바꾸기

둘러보기 중에는 화면 아래 **추천 테마** 막대에서 기본 배치와 4개 컨셉, 현재 컨셉의 색감을 바로 바꿉니다. 서 있는 위치와 시선은 그대로이고, 바뀐 가구가 몸과 겹치면 같은 방 안의 가까운 빈 곳으로 옮깁니다.

- PC: 마우스 잠금 상태에서도 숫자키 `1`(기본 배치)–`5`와 `C`(다음 색감)로 바꿉니다. Esc로 잠금을 풀면 막대를 클릭할 수 있고 **이어서 걷기**로 같은 위치에서 다시 걷습니다.
- 휴대폰·태블릿 터치 둘러보기: 왼쪽 위 **테마** 버튼을 누르면 목록이 열립니다. 방향키·시선 조작과 겹치지 않는 위치입니다.
- 컨셉 보기에서 가족 구성을 골랐다면 가장 잘 맞는 컨셉에 ‘추천’ 표시가 붙습니다.

공유 링크: `/?studio=1&concept=family-lounge&palette=walnut-navy`처럼 열면 세대에 들어가 목록에서 해당 컨셉을 적용한 상태로 시작합니다.

## 추천 기준

- 가족 구성이 컨셉의 주 대상이면 +3, 함께 맞는 대상이면 +1.5점입니다.
- 가족 구성별 필요 항목(잠자리 수, 공부·업무 자리, 식탁 인원, 아기 침대, 놀이 공간)을 **실제로 배치된 가구**로 세어 충족 비율 × 2점을 더합니다. 기본형에서 식탁이 작아지면 이 점수도 함께 내려갑니다.
- 분위기를 고르면 그 분위기의 색감을 가진 컨셉에 +1점을 주고, 그 색감을 미리 선택합니다.
- 점수는 화면 정렬용이며 실제 거주 적합성 평가가 아닙니다.

## 배치 방식과 점검

- 가구 위치는 좌표가 아니라 방 경계 기준 규칙(`min`/`max`/`mid`, 벽에서의 거리, 바라보는 방향)으로 적습니다. `src/concepts/planner.js`가 현재 평면(기본형·확장형)의 방 크기로 좌표를 계산하고, 맞지 않으면 후보 규칙이나 작은 대체 가구를 시도합니다.
- 결과는 스튜디오와 같은 `placementWarnings`로 점검합니다: 가구 겹침, 방 경계, 고정 집기, 가정한 문 개방 범위, 60cm 미만 여유.
- 4개 컨셉 × 기본형·확장형 모두 겹침·경계·문 개방 경고 없이 배치됩니다. 60cm 안내는 키즈 플레이 하우스의 아기 침대 한 건만 의도적으로 남깁니다(부모 침대 옆, 상세 화면에 이유 표시).
- 기본형은 주방 폭이 좁아 6인·4인 식탁 대신 2인 식탁을 놓고, 상세 화면에 그 사실과 ‘4인 이상 식탁’ 미충족을 표시합니다.

## 가구 형상과 색

- 컨셉 가구 28종은 `src/concepts/kit.js`가 둥근 모서리 박스를 조합해 코드로 만듭니다. 크기는 `src/concepts/furniture-spec.js`의 일반적인 국내 시판 규격 범위에서 정했으며 특정 제품의 실측이 아닙니다. 재질별로 메시를 합쳐 가구당 12개 이하로 유지합니다.
- 색감은 공유 재질 슬롯(패브릭·우드·포인트·러그 등)의 색을 바꾸고, 기존 모델의 패브릭·패널 일부도 같은 색으로 맞춥니다. 화면 표시용 색이라 실제 제품 색과 다를 수 있습니다.

## 기존 코드와의 연결

컨셉 코드는 `src/concepts/`(목록·상세 `concept-panel.js`, 둘러보기 테마 막대 `walk-themes.js`)에 있고, 스튜디오에는 다음 연결만 추가했습니다.

- `src/walkthrough/studio.js`: 상단 탭 이름(꾸미기), 장소 선택의 **전체 보기**, 확장 모듈에 넘기는 훅(`selectRoom`, `frame`, `refreshLayout`, `warnings`, `settle`, `standAt`, `resume` 등)과 모드·평면 전환 알림. 컨셉 보기 탭 버튼은 컨셉 모듈이 상단 탭에 추가합니다. 2D 평면은 높이 5cm 미만 가구(러그·매트)를 점선으로 그리고 짧은 `label`을 표시합니다.
- `src/walkthrough/main.js`: 가구가 바뀐 뒤 몸을 빈 곳으로 옮기는 `settle`, 지정 시점에서 걷기 시작하는 `standAt`, 위치를 유지한 채 다시 걷는 `resume`.
- `src/walkthrough/staging-assets.js`: 코드로 만든 가구를 편집 대상 템플릿으로 등록하는 `addTemplate`, 정해진 ID·좌표로 놓는 `place`.
- `src/walkthrough/layout.js`: 러그·매트처럼 바닥에 까는 가구는 다른 가구와 겹쳐도 경고하지 않습니다. 60cm 여유 점검은 **같은 방** 가구끼리만 합니다. 이전에는 벽 너머 가구까지 세어 기본 배치에서도 소파↔킹 침대 같은 잘못된 경고가 나왔습니다.

## 검증

- `tests/concepts.test.js`: 카탈로그 참조, 두 평면에서 경고 없는 배치, 가족 구성 충족, 추천 순서와 색감 선택, 가구 형상 치수, 색 적용, 러그·같은 방 규칙.
- `tests/concepts.browser.js`: 세 탭과 전체 보기, 가족 구성별 추천 순서, 적용 후 목록 유지, 카드 색감·마감·시간대·상세, 4개 컨셉 실제 적용과 스튜디오 경고, 되돌리기, 기본형 식탁 안내, 저장·복원, 공유 링크, 걸으며 숫자키·C·클릭으로 테마 전환(서 있는 위치 유지), 휴대폰 시트와 테마 버튼.

## 남은 일

- 컨셉은 112A 전용 규칙입니다. 다른 타입·인하대 도면에는 방 ID와 규칙을 새로 정의해야 합니다.
- 실제 판매 가구 GLB나 W7-04의 이미지 기반 가구로 바꾸면 kit 대신 그 모델을 같은 템플릿 경로로 넣을 수 있습니다.
- 사용자 조사로 가족 구성별 필요 항목과 점수 가중치를 다듬어야 합니다.
