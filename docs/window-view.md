# 창밖 풍경 (W7-07)

둘러보기의 창밖은 **ACRO 공식 단지 사진**을 기본으로 보여줍니다. 실제 22층 조망 사진은 아직 없기 때문에, 직접 찍은 360° 사진으로 창밖을 바꿔 보는 기능을 함께 두어 실제 조망 자료를 넣는 흐름을 시험할 수 있게 했습니다.

## 사용 방법

`/?studio=1`에서 112A에 들어가 **둘러보기** 탭을 엽니다. 왼쪽 패널에서:

- **창밖 참고 배경 보기**: 공식 사진 배경을 켜고 끕니다(기존 기능).
- **내 360° 사진으로 창밖 바꾸기**: 펼쳐서 창가에서 찍은 2:1 등장방형 파노라마를 고릅니다. 세대를 둘러싼 구에 입혀지고, **사진 방향 맞추기** 슬라이더로 창 방향에 맞춥니다. **공식 사진으로 돌아가기**를 누르면 원래 배경으로 돌아갑니다.
- 사진은 이 브라우저 안에서만 쓰고 서버로 보내지 않습니다. 비율이 2:1이 아니면 늘어나 보일 수 있다고 안내합니다.

화면 아래 안내 문구는 지금 보이는 배경을 구분합니다. 공식 사진일 때는 실제 22층 조망과 다를 수 있다는 점을, 360° 사진일 때는 직접 불러온 사진이며 방향을 수동으로 맞춘다는 점을 표시합니다.

## 실제 조망으로 가는 단계

1. **현장 촬영**: 112A 해당 층 창가에서 360° 사진을 찍고 방위를 기록합니다. 지금의 ‘내 360° 사진’ 흐름 그대로 넣을 수 있습니다.
2. **방향 고정**: 촬영 방위를 기준으로 사진 방향을 저장해 슬라이더 없이 바로 맞춥니다.
3. **공공 3D 데이터**: 필요하면 국토교통부 V-World 3D 건물·지형을 glTF로 바꿔 실제 주변 동을 배치합니다. 이용 약관과 키 발급 확인이 필요합니다.
4. **동·호수 확정**: 112A의 실제 동·층·향을 확인한 뒤 시점 위치를 고정합니다.

## 범위와 한계

- 공식 사진은 단지 소개 사진을 창밖에 배치한 시각 참고이며, 특정 동 22층에서 보이는 실제 조망은 아닙니다.
- 10월 9일에 시험한 OpenStreetMap 기반 방위 시뮬레이션은 10월 10일 피드백에 따라 삭제했습니다.
- 현관 밖 공간과 기존 공식 사진 배경은 그대로 두었습니다. `src/walkthrough/location.js`는 360° 사진을 쓰는 동안 사진 배경을 숨기고 다시 보일 수 있도록 그 그룹만 함께 반환합니다.

## 코드와 검증

- `src/window-view/window-view.js`: 둘러보기 패널의 360° 사진 선택, 구 배치·회전, 안내 문구 전환.
- `tests/concepts.browser.js`의 창밖 항목: 기본 공식 사진, 360° 사진 적용·방향·안내 문구, 공식 사진 복귀.
